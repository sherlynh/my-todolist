# 📝 My To-Do List Web App

Aplikasi web sederhana berbasis **HTML, CSS, dan JavaScript (Vanilla)** yang dirancang untuk mengelola daftar tugas harian secara interaktif dan efisien. Project ini dibuat untuk memenuhi penugasan praktikum manajemen tools pengembangan perangkat lunak menggunakan GitHub.

## ✨ Fitur Utama
- **Add Task:** Menambahkan tugas baru ke dalam daftar dengan cepat.
- **Interactive Check:** Menandai tugas sebagai selesai (mencoret teks) atau belum selesai.
- **Delete Task:** Menghapus tugas yang sudah tidak diperlukan.
- **Local Storage Integration:** Menyimpan data tugas langsung di browser pengguna sehingga data tidak hilang saat halaman ditutup atau direfresh.

## 🛠️ Teknologi yang Digunakan
- **HTML5** (Struktur markup semantik)
- **CSS3** (Styling modern, Flexbox, dan desain responsif)
- **JavaScript ES6+** (DOM Manipulation & Web Storage API)
